  Anthropic Claude-இன் வெளியீட்டுக்கு குறியிடத் தொடங்கியுள்ளது. உரைக்குப் புள்ளிவிவர வாட்டர்மார்க், கோப்புகளுக்கு C2PA கையொப்பமிட்ட மெட்டாடேட்டா, 2 ஆகஸ்ட் 2026 முதல் வெளியாகும் அனைத்துக்கும் மாடல் வாரியாக உலகம் முழுவதும் அறிமுகமாகிறது, EU AI Act வெளிப்படைத்தன்மை நெறிமுறையின் கீழ். நான் ஒரு கண்டறிப்பானை உருவாக்கப் புறப்பட்டேன், முடியவில்லை. முறை வெளியிடப்படவில்லை, சமிக்ஞை மாடலின் சொல் தேர்வுகளில் உள்ளது, தேடிக் கண்டுபிடிக்கக்கூடிய எந்த எழுத்திலும் இல்லை, ஒரு ஆவணத்துக்கு இரு ஆசிரியர்கள் இருந்தால் புள்ளிவிவரங்கள் மூன்று வரிகளில் வருவித்துக் காட்டக்கூடிய விதத்தில் சரிகின்றன. எனவே சரிபார்க்கக்கூடியதைச் சொல்லும், எதுவும் இல்லாதபோது அதையும் சொல்லும் கருவியை உருவாக்கினேன்.

நான் Anthropic-இன் அறிவிப்பைப் படித்து, பூஜ்ய-அகல எழுத்துகளைத் தேட ஒரு உரைத் திருத்தியைத் திறந்தேன். ஒன்றுமில்லை. வாட்டர்மார்க் எழுத்துகளுக்கு இடையில் ஒளிந்திருக்கவில்லை, மாடல் எந்தச் சொற்களைத் தேர்ந்தெடுத்தது என்பதில் உள்ளது, இதை ஏற்றுக்கொள்ள எனக்கு இருக்க வேண்டியதைவிட அதிக நேரம் ஆனது. அதாவது "வாட்டர்மார்க் அகற்றி"க்கு அகற்ற எதுவுமே இல்லை.

## மக்கள் வாட்டர்மார்க் என்று அழைக்கும் மூன்று விஷயங்கள்

மூன்று வெவ்வேறு பொறிமுறைகள் வாட்டர்மார்க் என்று அழைக்கப்படுகின்றன. அவற்றுக்கு இடையே கிட்டத்தட்ட எந்த ஒற்றுமையும் இல்லை.

|---|---|---|---|
| மறைக்கப்பட்ட Unicode | பூஜ்ய-அகல எழுத்துகள், Tag தொகுதி (U+E0000-E007F) | எந்தத் தேடு-மாற்று | ஆம், மிக எளிதாக |
| C2PA மெட்டாடேட்டா | கோப்புக் கொள்கலனில் கையொப்பமிட்ட மேனிஃபெஸ்ட் | திரைப்பிடிப்பு, மீண்டும் சேமிப்பு, வடிவ மாற்றம் | ஆம், இருப்பைச் சரிபார்க்கலாம் |
| புள்ளிவிவர வாட்டர்மார்க் | மாடலின் டோக்கன் தேர்வுகள் | கடுமையான பொழிப்புரை அல்லது மொழிபெயர்ப்பு | இல்லை, விற்பனையாளரின் விசை தேவை |

Anthropic இவற்றில் இரண்டைச் செயல்படுத்துகிறது. கோப்புகள் `.svg`, `.png`, `.jpg` இல் C2PA கையொப்பமிட்ட மூல மெட்டாடேட்டாவைப் பெறுகின்றன, படத் தொழில்துறை பயன்படுத்தும் அதே Content Credentials தரநிலை. உரை மூன்றாவது வரிசையைப் பெறுகிறது. Anthropic-இன் ஆவணங்கள் அதை "உரையிலேயே நேரடியாக அமைந்த புலப்படாத வாட்டர்மார்க்" என்று அழைக்கின்றன, அது "Claude-இன் பதிலின் பொருள், தரம் அல்லது படிக்கும் தன்மையை மாற்றாது".

வெளியீடு தலைப்புச் செய்திகள் குறிப்பிட்டதைவிட குறுகியது. Anthropic-இன் சொற்களில், "2 ஆகஸ்ட் 2026 அன்று அல்லது அதற்குப் பிறகு வெளியான Claude மாடல்கள் வெளியீட்டிலேயே இயந்திரம் படிக்கக்கூடிய குறியிடலை ஆதரிக்கும்", தற்போதைய மாடல்களுக்கான ஆதரவு நடந்துவரும் பணியாக விவரிக்கப்படுகிறது. பிரிவு மாடல் அடிப்படையில், நாடு அடிப்படையில் அல்ல. Claude எங்கு வழங்கப்பட்டாலும் ஆதரிக்கப்படும் மாடல்களின் வெளியீட்டுக்குக் குறியிடல் பொருந்தும், உலகம் முழுவதும் என்றும் அதே பக்கம் சொல்கிறது. இதன் பின்னால் உள்ள உந்துசக்தி EU AI Act-இன் பிரிவு 50(2) இன் கீழ் AI உருவாக்கிய உள்ளடக்கத்தின் வெளிப்படைத்தன்மை குறித்த நடத்தை நெறிமுறை, இதில் Anthropic மாடல் வழங்குநராகவும் உருவாக்க AI அமைப்பு வழங்குநராகவும் கையொப்பமிட்டது. எனவே இது மாடல் வாரியாக வருகிறது, ஒரு மாடலுக்கு வந்துவிட்டால் எல்லோருக்கும் கிடைக்கிறது.

Google சிறிது காலமாக Gemini முழுவதும் SynthID-Text-ஐ இயக்குகிறது, முறை Nature-இல் வெளியிடப்பட்டுள்ளது. இது மாதிரியெடுப்புப் படியை மட்டுமே மாற்றுகிறது. ஒவ்வொரு டோக்கனிலும் முந்தைய k டோக்கன்களைக் கொண்டு ஒரு போலி-சீரற்ற செயல்பாட்டை விதைக்கிறது, சொற்களஞ்சியத்தை m அடுக்குகள் கொண்ட போட்டி அட்டவணையாகப் பிரிக்கிறது, தங்கள் போட்டிகளில் தொடர்ந்து வெல்லும் டோக்கன்களின் மாதிரியெடுப்பு நிகழ்தகவை உயர்த்துகிறது. இதைப் போதுமான அடுக்குகள், போதுமான டோக்கன்கள் மீது பரப்பினால் அளவிடக்கூடிய புள்ளிவிவரச் சாய்வு கிடைக்கிறது, வாசகருக்கு எந்தத் தனிச் சொல்லும் தவறாகத் தெரியாது.

கண்டறிதலுக்கு மூல மாடல் தேவையில்லை. அதற்குத் தேவை விசையுள்ள போலி-சீரற்ற செயல்பாடும் சோதிக்கப்படும் உரையின் மீது ஒரு மதிப்பீட்டுச் சுற்றும். வாட்டர்மார்க் உள்ள உரை இல்லாத உரையைவிடத் தொடர்ந்து அதிக g-மதிப்புகளைக் கொண்டிருக்கும், அந்த இடைவெளியே ஒரு கருதுகோள் சோதனை.

Anthropic-இன் உதவிப் பக்கம் இதில் நேரடியாக உள்ளது. அவர்கள் "Claude-இல் பொதிந்த வாட்டர்மார்க்குகளையும் மூல மெட்டாடேட்டாவையும் பயனர்களும் பிற மூன்றாம் தரப்பினரும் கண்டறியும் வகையில் செயல்பட்டு வருகிறோம்" என்றும், "வரவிருக்கும் தொழில்நுட்ப ஆவணத்தில் கண்டறியும் பொறிமுறைகளின் விவரங்களைப் பகிர்வோம்" என்றும் கூறுகிறார்கள். வரவிருக்கும் என்றால் இன்னும் இல்லை. அது வரும்வரை Anthropic-க்கு வெளியே யாரும் உரை வாட்டர்மார்க்கைச் சரிபார்க்க முடியாது. சரிபார்க்கிறோம் என்று சொல்லும் எந்தக் கருவியும் வேறு பெயரில் ஒரு பொதுவான AI-உரை வகைப்படுத்தியை இயக்குகிறது, அவற்றின் பிழைச் சுயவிவரம் மிகவும் மோசம், குறிப்பாக இரண்டாம் மொழியில் எழுதுபவர்களுக்கு.

## ஆய்வுக் கருவியை உருவாக்குதல்

எனவே தான் சரிபார்க்கக்கூடியதை மட்டுமே கூறும் பதிப்பை உருவாக்கினேன்.

C2PA பக்கத்துக்குத்தான் அதிக குறியீடு தேவைப்பட்டது. Content Credentials மேனிஃபெஸ்ட் ஒரு JUMBF பெட்டியில் இருக்கும், அந்தப் பெட்டி எங்கே விழும் என்பது கொள்கலனைப் பொறுத்தது. PNG அதை `caBX` துண்டில் வைக்கிறது, JPEG அதை APP11 பகுதியில் சுமக்கிறது, SVG அதை XML மெட்டாடேட்டாவில் வைக்கிறது. அதைக் கண்டுபிடிப்பது என்றால் மூல பைட்டுகளில் அந்தக் குறிப்பான்களுக்காக ஸ்கேன் செய்வது:

```ts
const scanC2PA = (buf: ArrayBuffer) => {
  const bytes = new Uint8Array(buf);

  const find = (needle: string): boolean => {
    const n = needle.length;
    const limit = bytes.length - n;
    for (let i = 0; i <= limit; i++) {
      let ok = true;
      for (let j = 0; j < n; j++) {
        if (bytes[i + j] !== needle.charCodeAt(j)) { ok = false; break; }
      }
      if (ok) return true;
    }
    return false;
  };

  const isPng = bytes[0] === 0x89 &&
    String.fromCharCode(bytes[1], bytes[2], bytes[3]) === 'PNG';

  const hasJumbf  = find('jumb') || find('jumd');
  const hasC2pa   = find('c2pa');
  const hasPngBox = isPng && find('caBX');

  return { found: hasC2pa || hasPngBox, hasJumbf, isPng };
};
```

அது ஒரு மேனிஃபெஸ்டைக் கண்டுபிடிக்கிறது. அதைச் சரிபார்ப்பதில்லை. சரிபார்ப்பு என்றால் சான்றிதழ் சங்கிலியையும் குறியாக்கக் கையொப்பத்தையும் சோதிப்பது, அதை உலாவித் தாவலில் கையால் எழுதி அதிகாரபூர்வமாக முன்வைக்கப் போவதில்லை. கருவி அதைச் சொல்லி அதிகாரபூர்வ சரிபார்ப்பியை நோக்கிச் சுட்டுகிறது.

ஸ்கேனுக்கு ஒரு தோல்வி நிலை உள்ளது, அதை மறைக்காமல் பெயரிட்டுச் சொல்ல வேண்டும். மூல பைட்டுகளில் நான்கு எழுத்துக் குறிப்பானைத் தேடினால் தவறான நேர்மறை வரலாம், ஏனெனில் சுருக்கப்பட்ட பட தரவுக்குள் `c2pa` பைட்டுகள் தோன்றுவதை எதுவும் தடுக்காது. அப்படியிருந்தும் அதை வைத்திருந்தேன். மூன்று வடிவங்களில் கொள்கலன் அமைப்பைச் சரியாகப் பிரித்தாய்வது, "இங்கே ஏதோ இருக்கிறது, வேறெங்காவது சரிபாருங்கள்" என்பதே முழு வாதமாக உள்ள கருவிக்கு மிகுந்த உழைப்பு. இது ஒரு புகை எச்சரிக்கை, லேபிளும் அதையே சொல்கிறது. எப்போதாவது இது போதாமல் போனால், தீர்வு உண்மையான பெட்டி பகுப்பாய்வு.

உரைப் பக்கம் என் மறைக்கப்பட்ட-உரை ஆய்வுக் கருவியின் குறியீட்டுப்புள்ளி ஸ்கேனரை மீண்டும் பயன்படுத்துகிறது: பூஜ்ய-அகல எழுத்துகள், முழு ASCII செய்திகளையே கண்ணுக்குத் தெரியாமல் கடத்தக்கூடிய Unicode Tag தொகுதி, bidi கட்டுப்பாடுகள், மாறுபாடு தேர்விகள். இவை அனைத்தும் கண்டறியத்தக்கவை, குறிக்கத்தக்கவை.

கடினமான பகுதி குறியீடு அல்ல. அது ஒரே தீர்ப்பின் சொற்கள். கருவியில் "புள்ளிவிவர வாட்டர்மார்க் (Claude, SynthID-Text)" என்ற சமிக்ஞை உள்ளது, அதன் நிரந்தர நிலை `not checkable`, விளக்கத்துடன். வெளியிடும் முன் இதைப் பற்றி நீண்ட நேரம் யோசித்தேன், ஏனெனில் "எனக்குத் தெரியாது" என்று பதில் தரும் கருவி உடைந்ததுபோல் தெரியும்.

இந்த முடிவுகள் எப்படிப் பயன்படுத்தப்படுகின்றன என்பதால் இது முக்கியம். யாரோ ஒரு பத்தியை சரிபார்ப்பியில் இட்டு வெளியீட்டை ஒழுங்கு நடவடிக்கைக் கூட்டத்துக்கு எடுத்துச் செல்கிறார்கள். எனவே கருவி நான்கு எச்சரிக்கைகளுடன் தொடங்குகிறது. முதல் இரண்டு Anthropic-இன் சொந்த நிலைப்பாடு, மற்ற இரண்டு நான் உருவாக்கியதன் வரம்புகள் பற்றிய என்னுடையவை:

- குறி இல்லாதது மனித ஆசிரியத்துவத்துக்கான சான்று அல்ல. கடுமையான திருத்தம், பொழிப்புரை, மொழிபெயர்ப்பு, பிற எழுத்துடன் இணைத்தல் ஆகியவற்றைக் குறிகள் கண்டறிய முடியாத நிலைமைகளாக Anthropic பட்டியலிடுகிறது.
- குறி இருப்பதும் ஆசிரியத்துவத்துக்கான சான்று அல்ல. உள்ளடக்கம் அந்த மாடலால் செயலாக்கப்பட்டிருக்கலாம் என்பதை அது குறிக்கிறது, யார் எழுதினார் என்பதையோ மனிதர் எவ்வளவு மாற்றினார் என்பதையோ அல்ல.
- C2PA இருப்பு C2PA சரிபார்ப்பு அல்ல. இந்தக் கருவி ஒரு மேனிஃபெஸ்டைக் கண்டுபிடிக்கிறது, கையொப்பத்தையோ வழங்குநரையோ சரிபார்ப்பதில்லை.
- மெட்டாடேட்டா எளிதில் உடையும். திரைப்பிடிப்புகள், மீண்டும் சேமிப்பு, பெரும்பாலான தள பதிவேற்றங்கள் அதை நீக்கிவிடும், எனவே பதிவிறக்கிய கோப்பில் தூய முடிவு மூலத்தைப் பற்றி மிகக் குறைவாகவே சொல்கிறது.

## ஒரு ஆவணத்துக்கு இரு ஆசிரியர்கள் இருக்கும்போது என்ன நடக்கிறது

மேலே உள்ள அனைத்தும் ஒவ்வொரு ஆவணத்துக்கும் ஒரு ஆசிரியர் என்று கருதுகின்றன. கிட்டத்தட்ட எதற்கும் ஒருவர் இல்லை. மக்கள் ஒரு சாட்பாட்டில் வரைவு எழுதுகிறார்கள், ஒரு பகுதியை இன்னொன்றில் மீண்டும் எழுதுகிறார்கள், அந்த வாரம் மலிவானது எதுவோ அதற்கு OpenRouter வழியாகச் செலுத்துகிறார்கள், இடையில் கையால் திருத்துகிறார்கள். இது அரிதான தப்பிக்கும் உத்தி அல்ல, இப்போது மக்கள் வேலை செய்யும் விதம் இதுதான்.

Anthropic ஏற்கனவே இதைக் குறிப்பிடுகிறது. குறி கண்டறிய முடியாத நிலைமைகளின் அவர்களின் பட்டியலில் "கடுமையாகத் திருத்தப்பட்ட, பொழிப்புரை செய்யப்பட்ட, மொழிபெயர்க்கப்பட்ட அல்லது பிற எழுத்துடன் இணைக்கப்பட்ட" உரை உள்ளது. அவர்கள் இதை எச்சரிக்கையாகச் சொல்லி அங்கேயே விட்டுவிடுகிறார்கள். பொறிமுறை இதோ, ஏனெனில் விளைவின் அளவு என்னை ஆச்சரியப்படுத்தியது.

பசுமைப் பட்டியல் கண்டறிதல் என்பது டோக்கன் எண்ணிக்கைகள் மீதான z-சோதனை. இது வெளியிடப்பட்ட பசுமைப் பட்டியல் கட்டமைப்பு, விளக்க அளவுருக்களுடன். இது Anthropic-இன் திட்டம் அல்ல, அது வெளியிடப்படவில்லை. முடிவின் வடிவம் பொருந்தும், குறிப்பிட்ட எண்கள் பொருந்தாது.

```
z = (greens - γT) / sqrt(T · γ(1-γ))
```

ஒரு ஆவணத்தில் `T` டோக்கன்கள் உள்ளன என்றும், அவற்றில் `W` மட்டுமே இயந்திரம் எழுதியவை என்றும், ஒவ்வொன்றும் பசுமை விகிதத்தை `ε` அளவுக்கு உயர்த்துகிறது என்றும் வைத்துக்கொள்வோம். மனித டோக்கன்கள் அடிப்படை விகிதம் `γ` இல் பசுமையைத் தருகின்றன, எனவே எதிர்பார்க்கும் பசுமை எண்ணிக்கை `Tγ + Wε`, முழு ஆவணப் புள்ளிவிவரம் இவ்வாறு ஆகிறது:

```
z_whole = W·ε / sqrt(T · γ(1-γ))
```

இப்போது இயந்திரம் எழுதிய பகுதியை மட்டும் மதிப்பிடுங்கள்:

```
z_span  = ε·sqrt(W) / sqrt(γ(1-γ))
```

ஒன்றை மற்றதால் வகுத்தால் எல்லாம் ரத்தாகி ஒரே எண் மிஞ்சும்:

```
z_whole / z_span = sqrt(W/T) = sqrt(f)
```

முழு ஆவணத்தையும் மதிப்பிட்டால் உங்கள் கண்டறியும் ஆற்றலில் இயந்திரம் எழுதிய விகிதத்தின் வர்க்கமூலம் மட்டுமே மிஞ்சும். `f = 0.1` இல் அது 32%. விளக்க மதிப்புகளாக `γ = 0.5` மற்றும் பசுமை விகித உயர்வு `ε = 0.25` எடுத்தால், 300 டோக்கன் இயந்திர-எழுத்துப் பகுதி தனியாக `z = 8.66` பெற்று மிகப் பெரிய நம்பிக்கையுடன் குறிக்கப்படும். அதே பகுதியை 3,000 டோக்கன் ஆவணத்தில் போட்டால் முழு ஆவண மதிப்பெண் `z = 2.74` ஆகக் குறைகிறது, எந்த நியாயமான வரம்புக்கும் கீழே. வாட்டர்மார்க் மாறவில்லை. கண்டறிப்பான் தவறான அலகை அளந்தது.

எனவே மாடல்களைக் கலப்பது வாட்டர்மார்க்கைத் தாக்குவதில்லை. அது கண்டறிப்பானின் சாளரத் தேர்வைத் தாக்குகிறது.

தீர்வு உரை முழுவதும் ஒரு சாளரத்தை நகர்த்தி அதிகபட்ச மதிப்பெண்ணை எடுப்பது, SynthID-Text ஆய்வுக்கட்டுரையின் WinMax கருத்து ஏறத்தாழ இதுவே. இது வேலை செய்கிறது, ஆனால் விலை உண்டு. நூற்றுக்கணக்கான ஒன்றன்மேல் ஒன்றாகும் சாளரங்களை மதிப்பிடுவது என்றால் ஒரே ஆவணத்தில் நூற்றுக்கணக்கான கருதுகோள் சோதனைகளை இயக்குவது, எனவே பல-ஒப்பீட்டுத் திருத்தம் தேவை, அது வரம்பை மேலே தள்ளுகிறது, அது குறுகிய பகுதிகளை மீண்டும் அதற்குக் கீழே தள்ளுகிறது. நீங்கள் நீர்த்துப்போகும் சிக்கலைத் தவறான நேர்மறைச் சிக்கலுடன் மாற்றிக்கொள்கிறீர்கள், அந்தக் கைப்பிடியின் எந்த அமைப்பும் இரண்டையும் தவிர்ப்பதில்லை.

சாளரமாக்கலும் ஒரு விற்பனையாளரின் குறியை மட்டுமே இடம்காட்டும், ஏனெனில் ஒவ்வொரு வழங்குநரும் தன் போலி-சீரற்ற செயல்பாட்டை தன் சொந்த விசையுடன் இயக்குகிறார்:

```
for each vendor key K:          # Anthropic, Google, OpenAI, ...
    for each window w in text:  # all of these need FPR correction together
        score(w, K)
```

மூன்று விற்பனையாளர்கள் என்றால் மூன்று கண்டறிப்பான்கள், மூன்று API சுற்றுப் பயணங்கள், மூன்று நம்பிக்கை உறவுகள். கூட்டமைப்புப் பதிப்பை யாரும் வழங்குவதில்லை, Anthropic-இன் பதிப்பு இன்னும் பொதுவில் இல்லை.

பிறகு மேலே உள்ளவற்றில் பெரும்பாலானவற்றை கல்விசார்ந்ததாக்கும் ஓட்டை இருக்கிறது. வாட்டர்மார்க்கிங்குக்கு அனுமானத்தை இயக்குபவர் மாதிரியெடுப்புப் படியைச் சாய்க்க வேண்டும். அது சேவைத் தொகுப்பின் பண்பு, உரையின் பண்பு அல்ல. எனவே:

| பாதை | வாட்டர்மார்க் உண்டா? | ஏன் |
|---|---|---|
| OpenRouter → Claude / Gemini / GPT | ஆம் | டோக்கன்களைத் திருப்பி அனுப்பும் முன் வழங்குநரின் தொகுப்புக்குள் பயன்படுத்தப்படுகிறது. வழிப்படுத்தி முடிந்த உரையை மட்டும் அனுப்புகிறது. |
| OpenRouter → Llama / Qwen / Mistral | இல்லை | திறந்த-எடை அனுமான வழங்குநர்களுக்கு சாய்ந்த மாதிரியெடுப்பைச் செயல்படுத்தும் கடமையும் இல்லை, ஊக்கமும் இல்லை. |
| உங்கள் சொந்த மடிக்கணினியில் llama.cpp | இல்லை | அதே காரணம், இன்னும் அதிகமாக. |

OpenRouter வழிப்படுத்துவதால் வாட்டர்மார்க்கைத் தோற்கடிக்கவில்லை. குறி ஒருபோதும் இடப்படாத பாதையை அது வழங்குகிறது, அந்தப் பாதை ஒரு கட்டமைப்புச் சரத்தின் தொலைவில் உள்ளது. எனவே இந்த ஆட்சிமுறை தனியுரிமை முன்னணி API-களை மட்டுமே உள்ளடக்குகிறது, வேறெதுவும் இல்லை. திறந்த எடைகள் பெரும்பாலான உரைப் பணிகளுக்கு ஏற்கனவே போதுமான அளவு நல்லவை, அவை இதற்கு வெளியே உள்ளன. இதைச் சுற்றிப் போக விரும்புபவர் ஒரு மாடல் பெயரை மாற்றுகிறார்.

நீர்த்துப்போகும் விளைவை ஆய்வுக் கருவியில் மூன்றாவது தாவலாகச் சேர்த்தேன். அது எந்த உரையையும் பகுப்பாய்வு செய்வதில்லை, எதையும் கண்டறிவதில்லை. z-சோதனைக் கணிதத்தை இயக்கி, இயந்திரம் எழுதிய பகுதியை மாற்றும்போது இரு மதிப்பெண்களும் எப்படிப் பிரிகின்றன என்பதை வரைகிறது.

## நான் எங்கே தவறினேன்

வாட்டர்மார்க் நீடித்து நிற்பது திருத்தங்களைத் தாங்குவது என்று நான் கருதியிருந்தேன். அது பொழிப்புரையைத் தாங்குவது, அது மிகவும் கடினம், ஏனெனில் பொழிப்புரை டோக்கன் தேர்வுகளை மீண்டும் மாதிரியெடுக்கிறது, சமிக்ஞை வாழ்வது அங்கேதான். என் முதல் திட்டம் நம்பிக்கைச் சதவீதம் கொண்ட சரிபார்ப்பி, ஏனெனில் மக்கள் எதிர்பார்ப்பது அதுதான், தரவரிசையில் வருவதும் அதுதான். அதைக் கொன்றேன். நான் உருவாக்கும் எந்த எண்ணும் வேறு லேபிளின் கீழ் ஒரு பொதுவான AI-உரை வகைப்படுத்தியாக இருந்திருக்கும், அவற்றுக்கு ஆவணப்படுத்தப்பட்ட தவறான நேர்மறைச் சிக்கல்கள் உண்டு, குறிப்பாகத் தாய்மொழி ஆங்கிலம் அல்லாத எழுத்தாளர்களுக்கு எதிராக.

கடினமான முடிவு வாட்டர்மார்க் அகற்றி, உண்மையில் போக்குவரத்தை இழுக்கக்கூடிய அருகிலுள்ள தயாரிப்பு. அதை விட்டுவிட்டேன். அது வெளிப்படுத்தல் உறுதிப்பாட்டைச் சுற்றிப்போக உதவும் கருவியாக இருக்கும், எப்படியும் வேலை செய்யாது. நீக்க எழுத்து எதுவும் இல்லை, எனவே நீக்குவது என்றால் எழுத்தைச் சீரழிக்கும் அளவுக்கு ஆக்ரோஷமான பொழிப்புரை, உலாவிக் கருவி ஒரு மாடலை அனுப்பாமல் பொழிப்புரை செய்ய முடியாது. பின்னர் என்னோடு தங்கிய விஷயம், இதனுடன் நான் வெளியிட்ட நிறுத்தற்குறி திருத்தி பூஜ்ய-அகல எழுத்துகளை நீக்குகிறது, அது என் சொந்த வரைவுகளுக்கு நான் விரும்பிய சுத்தம். அதே ரெஜெக்ஸ், வேறு தயாரிப்பு. எல்லைக்கோடு குறியீட்டில் இல்லை, கருவி எதற்காக என்று பக்கம் சொல்வதில் உள்ளது.

## இது எங்கே போகிறது

விற்பனையாளர் மட்டுமே சரிபார்க்கக்கூடிய மூலச் சமிக்ஞை இன்னும் பொது மூலச் சான்று அல்ல. ஆனால் sqrt(f) முடிவு "ஆயுதப் போட்டி தொடர்கிறது" என்பதைவிட குறிப்பிட்ட ஒன்றை நோக்கிச் சுட்டுகிறது. உள்ளடக்கத்தை மட்டும் சார்ந்த தடயவியல் மக்கள் உண்மையில் கேட்கும் கேள்விக்குப் பதில் சொல்ல முடியாது. உரை உருவாக்கப்பட்டதா என்பதல்ல, எந்தப் பகுதிகள், யாரால், மனிதர் எவ்வளவு மாற்றினார் என்பது. நம்மிடம் உள்ள ஒவ்வொரு பொறிமுறையும் உண்மையான ஆவணங்கள் இருக்கும் இடத்தில்தான் சிதைகிறது, பல ஆசிரியர்களும் நீண்ட திருத்த வரலாறும் கொண்ட கோப்புகளில். எனவே பயனுள்ள நகர்வு உரையை விசாரிப்பதை நிறுத்தி சூழலைப் பதிவு செய்யத் தொடங்குவதுதான். திருத்தியின் திருத்த வரலாறு, கமிட் காலவரிசைகள், கையொப்பமிட்ட திருத்தச் சங்கிலிகள் முடிந்த படைப்பின் மீதான எந்தப் புள்ளிவிவரச் சோதனையையும்விட மிகவும் நம்பகமாக ஆசிரியத்துவத்தைப் பிடிக்கின்றன, C2PA-இன் வலியுறுத்தல் மாதிரி இந்த வகையான அடுக்கடுக்கான, பல தரப்பு மூலச் சான்றை இலக்காகக் கொள்கிறது. வாட்டர்மார்க்கின் உண்மையான வேலை தலைப்புச் செய்திகள் குறிப்பிட்டதைவிடக் குறுகியது. இது யாரும் மறைக்க முயலாத இயந்திர உரைக்கான இயல்பாகவே இயங்கும் வெளிப்படுத்தல், எதிரி நிலைகள் எப்போதும் இருக்க வேண்டிய இடத்தில் கையாளப்படுகின்றன, ஆவணம் எப்படி உருவாக்கப்பட்டது என்பதைப் பதிவு செய்யும் கருவிகளில்.
