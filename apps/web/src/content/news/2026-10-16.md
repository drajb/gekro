Meta released Muse Spark Open, an 816-billion-parameter open-weight mixture-of-experts model with 42 billion active parameters and 1 million token context window ([MarkTechPost](https://www.marktechpost.com/2026/10/15/meta-muse-spark-open-816b-open-weight-model/)). The model processes text, images, video, and audio, and is optimized to run locally on Apple silicon through collaboration with Apple ([The Decoder](https://the-decoder.com/muse-spark-open-is-metas-answer-to-qwen-glm-and-kimi-in-the-open-weight-race/)). Performance on open-model benchmarks places it roughly on par with leading open-weight Chinese models ([The Decoder](https://the-decoder.com/muse-spark-open-is-metas-answer-to-qwen-glm-and-kimi-in-the-open-weight-race/)), and the model runs on two M5 Ultra Mac Studios ([MarkTechPost](https://www.marktechpost.com/2026/10/15/meta-muse-spark-open-816b-open-weight-model/)).

NVIDIA released Nemotron 3.5 Super VL, a 120-billion-parameter open multimodal mixture-of-experts agent model with 12 billion active parameters, 1 million token context, and NVFP4 quantized weights that run on a single DGX Spark, plus two compact Bolt models for edge deployment ([MarkTechPost](https://www.marktechpost.com/2026/10/15/nvidia-nemotron-3-5-super-vl-release/)). The model targets enterprise agent deployment ([The Decoder](https://the-decoder.com/nvidias-nemotron-3-5-super-vl-is-an-open-model-built-to-run-enterprise-ai-agents-nonstop/)), with dozens of organizations already fine-tuning it ([The Decoder](https://the-decoder.com/nvidias-nemotron-3-5-super-vl-is-an-open-model-built-to-run-enterprise-ai-agents-nonstop/)). Separately, Black Forest Labs released FLUX 3 Image Klein, a 5.6-billion-parameter open-weights image generation model supporting 4K native output, pixel-precise editing, and multi-reference image generation that runs on consumer GPUs with 8 GB of VRAM ([The Decoder](https://the-decoder.com/black-forest-labs-open-weights-image-model-flux-3-image-klein-runs-on-consumer-gpus-with-just-8-gb-of-vram/)).
