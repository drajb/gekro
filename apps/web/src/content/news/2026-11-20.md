Nvidia released Nemotron-Labs-Sigma, a suite of 14 open-weight continuous diffusion language model checkpoints at 3B and 8B parameters ([MarkTechPost](https://www.marktechpost.com/2026/11/20/nvidia-nemotron-labs-sigma-continuous-diffusion-language-model/)). The models denoise text in a learned 16-dimensional embedding space, support distillation to few-step samplers, and achieve up to 4.20x faster decoding compared to autoregressive decoding. The release strengthens Nvidia's open-source Nemotron lineup, following reports that the company is acquiring AI startup Inception for at least $500 million to expand its diffusion-based model portfolio ([The Decoder](https://the-decoder.com/nvidia-bets-at-least-500-million-on-inceptions-diffusion-models-to-strengthen-its-open-source-nemotron-lineup/)).

Perplexity launched the Orchestrator API, which routes requests across OpenAI, Anthropic, Google, xAI, and open-weight models through a single endpoint ([MarkTechPost](https://www.marktechpost.com/2026/11/19/perplexity-orchestrator-api-failover-model-routing/)). The API provides same-model provider failover, unified billing, and a preview auto-router that directs each request to specified routes. Meta FAIR's Self-Improving Memory system scored 56.0 on the Continual Learning Bench, outperforming hand-written baselines at 44.6, by enabling models to write and distill their own memory prompts into weights ([MarkTechPost](https://www.marktechpost.com/2026/11/19/meta-fair-self-improving-memory-harness-distillation/)).
