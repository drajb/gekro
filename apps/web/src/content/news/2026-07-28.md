Microsoft AI released MAI-Cyber-1-Flash, a 137B total parameter model with 5B active parameters built as a sparse MoE fine-tune of MAI-Code-1-Flash, designed to run within Microsoft's MDASH multi-agent system for cyber defense ([MarkTechPost](https://www.marktechpost.com/2026/07/28/microsoft-ai-releases-mai-cyber-1-flash-a-5b-active-parameter-cyber-model-that-pushes-mdash-to-95-95-on-cybergym/)). The model achieves 95.95% on CyberGym and includes a 256k context window ([The Decoder](https://the-decoder.com/microsoft-launches-its-own-cybersecurity-model-mai-cyber-1-flash-but-still-depends-on-openai-for-the-toughest-tasks/)). According to Microsoft, the system reduces costs by approximately 50 percent compared to pure frontier models by routing only complex cases to GPT-5.4 ([The Decoder](https://the-decoder.com/microsoft-launches-its-own-cybersecurity-model-mai-cyber-1-flash-but-still-depends-on-openai-for-the-toughest-tasks/)).

Moonshot AI released Kimi K3's model weights alongside open-source infrastructure components ([The Decoder](https://the-decoder.com/moonshot-ai-releases-kimi-k3-open-weights-and-infrastructure-after-shaking-up-the-frontier-model-race/)). The company and kvcache-ai open-sourced AgentENV under MIT license, a distributed system that powers agentic reinforcement learning training by running agent sandboxes as Firecracker microVMs with millisecond snapshot, resume, and 16-way fork capabilities behind an E2B-compatible API ([MarkTechPost](https://www.marktechpost.com/2026/07/27/kimi-ai-and-kvcache-ai-open-sources-agentenv/)). Perplexity released pplx, a single-binary CLI tool exposing its Search API through terminal commands for coding agents, shipping as a checksum-verified binary for macOS arm64 and Linux with an Agent Skills module ([MarkTechPost](https://www.marktechpost.com/2026/07/27/perplexity-releases-pplx/)).
