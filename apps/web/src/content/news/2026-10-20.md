Cloudflare has released Clairic, a System One extraction model available on Workers AI that returns typed values with confidence scores in a single forward pass ([MarkTechPost](https://www.marktechpost.com/2026/10/20/cloudflare-releases-clairic-a-system-one-extraction-model-on-workers-ai/)). The model is positioned as faster and cheaper than large language models for document data extraction, with pricing at $0.10 per million input tokens and no output token charges ([The Decoder](https://the-decoder.com/cloudflares-clairic-pulls-data-from-documents-faster-and-cheaper-than-llms/)).

Inception released Mercury 3, a diffusion LLM achieving 1,068 tokens per second throughput with 1M-token context window ([MarkTechPost](https://www.marktechpost.com/2026/10/19/inception-mercury-3-diffusion-llm/)). On Inception's benchmark table, Mercury 3 leads GPT-6 Luna and Claude Haiku 5.5 on 8 of 12 evaluation tasks. Additionally, Nace AI released Drex Max, a multimodal decision model for computer-use agents that reads text and screenshots, scoring 67.59 on Decision Index 0.3.2 at $0.06 per million input tokens ([MarkTechPost](https://www.marktechpost.com/2026/10/19/nace-ai-drex-max-multimodal-decision-model/)).
