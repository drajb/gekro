DeepSeek has released V4.1-Flash-1017, an open-weight model checkpoint that outperforms its predecessor on agentic task benchmarks while reducing per-task inference costs ([The Decoder](https://the-decoder.com/deepseek-v4-1-flash-1017-beats-larger-rivals-in-agentic-tasks-while-once-again-massively-cutting-per-task-costs/)). The release is live across the DeepSeek website, app, and API. DeepSeek also opened new Search and Fetch APIs at $0.75 per 1,000 calls, expanding developer access to internal search infrastructure ([The Decoder](https://the-decoder.com/deepseek-v4-1-flash-1017-beats-larger-rivals-in-agentic-tasks-while-once-again-massively-cutting-per-task-costs/)). The model demonstrates faster task completion and shorter outputs than the September V4.1-Flash checkpoint ([MarkTechPost](https://www.marktechpost.com/2026/10/17/deepseek-just-released-v4-1-flash-1017-scores-77-0-on-deepswe-opens-search-api/)).

StepFun released Step 5 Preview as open-weight FP8 and BF16 checkpoints on Hugging Face and ModelScope ([MarkTechPost](https://www.marktechpost.com/2026/10/16/stepfun-releases-step-5-preview-open-weights-600b-moe-27b-active-1m-context/)). The sparse mixture-of-experts model contains 600B total parameters with 27B active per token and supports up to 1M token context windows, targeting long-horizon agentic applications. Perplexity open-sourced SPACE, its Firecracker microVM sandbox platform for AI agent task execution, under Apache 2.0 on GitHub ([MarkTechPost](https://www.marktechpost.com/2026/10/16/perplexity-open-sources-space-firecracker-microvm-sandbox-ai-agents/)), providing isolated compute environments with external credential and traffic control for sandbox-based agent workflows.
