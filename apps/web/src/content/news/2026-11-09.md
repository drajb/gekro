Baidu released ERNIE Evolve, an automated research system that edits code, runs experiments, and retains only verified performance gains. The system beat public records on NanoChat and NanoGPT Speedrun benchmarks and accelerated inference on ERNIE-5.5-Flash ([MarkTechPost](https://www.marktechpost.com/2026/11/09/baidu-ernie-evolve-automated-research-system/)).

Google expanded its TPU 8 family with two specialized variants: the TPU 8tx encrypts sensitive data during processing, while the TPU 8i Max doubles compute power and memory by co-packaging two chips on a single module. Google reported nearly 100 external customers now using its TPU portfolio as it competes with Nvidia ([The Decoder](https://the-decoder.com/google-ships-four-tpu-variants-in-one-year-as-it-ramps-up-competition-with-nvidia/)). Separately, Reason Machines open-sourced Aspen, a self-hosted Git server for AI agents that sustained 567 pushes per second on an 8-core server ([MarkTechPost](https://www.marktechpost.com/2026/11/09/reason-machines-aspen-open-source-git-server-ai-agents/)), and 0sec Labs released 0, an AI security harness for code review and pentesting that runs locally via browser, CLI, and MCP integration ([MarkTechPost](https://www.marktechpost.com/2026/11/08/0sec-labs-open-sources-0-ai-security-harness/)).
