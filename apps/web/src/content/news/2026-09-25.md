Meta has deployed a cloud Ubuntu Linux environment to over 500,000 Muse users, enabling installation of software, code writing, and web browsing within a sandboxed workspace. A process called Sentinel monitors sensitive system actions outside the user's designated workspace, while users retain full visibility into the filesystem ([The Decoder](https://the-decoder.com/metas-muse-agent-gives-every-user-a-full-cloud-computer-running-ubuntu-linux/)).

Black Forest Labs launched FLUX 3 Action, an open-weight robotics model with seven billion parameters that predicts robot actions from camera feeds. The model set a new RoboLab-120 benchmark record while achieving up to 3.95x faster inference than the previous top performer ([The Decoder](https://the-decoder.com/black-forest-labs-launches-flux-3-action-an-open-robotics-ai-model/)). Separately, PrismML deployed tiny open-weight language models to Qualcomm-powered smart glasses, focusing on on-device inference that leverages existing device compute ([TechCrunch](https://techcrunch.com/2026/09/24/prismml-brings-its-tiny-llms-to-qualcomm-powered-smart-glasses/)).
