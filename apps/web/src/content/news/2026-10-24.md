Anthropic released sandbox-runtime (srt), an open-source OS-level sandbox that restricts file and network access for AI agents, MCP servers, and CLI tools without requiring containers. The system uses Seatbelt on macOS and bubblewrap on Linux, and powers the sandbox behind Claude Code. ([MarkTechPost](https://www.marktechpost.com/2026/10/24/anthropic-sandbox-runtime-ai-agent-sandbox/))

Moonshot AI released Kimi K3.1 Pro, a 2.8-trillion-parameter MoE model with 104 billion active parameters and 1 million token context window, scoring 55 points on the Artificial Analysis Intelligence Index and ranking fourth globally behind only Anthropic and Meta models. ([MarkTechPost](https://www.marktechpost.com/2026/10/23/moonshot-ai-kimi-k3-1-pro-open-weight-model/)) Open weights are planned by November 4, 2026. ([The Decoder](https://the-decoder.com/chinese-ai-model-kimi-k3-1-pro-is-closing-in-on-anthropics-claude-opus-5-5/)) In separate work, NVIDIA released Nemotron 3.5 Bolt E4B, an open small language model targeting about 4GB of VRAM for local voice agents and robotics applications. ([MarkTechPost](https://www.marktechpost.com/2026/10/23/nvidia-nemotron-3-5-bolt-e4b-4gb/))
