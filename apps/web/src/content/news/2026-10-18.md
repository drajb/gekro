Google Research released Harness2, an Apache-2.0 licensed framework that rewrites an agent's harness at test time to improve performance. One refinement step using Harness2 lifted GLM-5 by 11.5 points on WorkBuddy-Bench with no weight updates, indicating a mechanism for post-hoc agent optimization without model retraining ([MarkTechPost](https://www.marktechpost.com/2026/10/18/google-harness2-recursive-agent-harnessing-framework/)).

Voxel51 released version 3.0, unifying search, curation, annotation and evaluation of multimodal sensor data into a single platform. The update includes Voxel51 Agent with 45+ Model Context Protocol (MCP) tools, dataset versioning, and a free self-service tier, targeting physical AI teams working with sensor data ([MarkTechPost](https://www.marktechpost.com/2026/10/17/voxel51-3-0-physical-ai-data-platform/)). Separately, Perplexity open-sourced SPACE, a Firecracker microVM sandbox platform for AI agents under Apache 2.0, with each agent task running in isolated VMs and credentials controlled externally ([MarkTechPost](https://www.marktechpost.com/2026/10/16/perplexity-open-sources-space-firecracker-microvm-sandbox-ai-agents/)).
