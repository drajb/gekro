Microsoft shipped Visual Studio Code 1.124 on June 10, making GitHub Copilot Autopilot the default permission level for agent sessions so that agents can complete tasks without requiring step-by-step user approval for each action ([VS Code](https://code.visualstudio.com/updates/v1_124)). An Advanced Autopilot option adds a secondary utility model that reads the session transcript and caps autonomous agent loops at three iterations - providing a guard against runaway execution ([TechTimes](https://www.techtimes.com/articles/318164/20260610/vs-code-1124-enables-copilot-autopilot-default-advanced-mode-caps-autonomous-loops-three.htm)). The release also introduces background session dispatch (Alt+Enter queues a new agent request without pausing the active session) and a persistent Agents Window that syncs session history across machines, allowing developers to resume agent work on different devices without losing context ([VS Code](https://code.visualstudio.com/updates/v1_124)). Enterprise administrators gain centralized control over which Copilot chat plugins and plugin marketplaces developers can access, replacing per-developer manual configuration ([Neowin](https://www.neowin.net/news/microsoft-releases-visual-studio-code-1124-with-smarter-autonomous-ai-agents/)).

On June 11, OpenAI launched rate-limit reset banking for Codex, giving subscribers on Go, Plus, Pro, and Business plans the ability to save unused daily resets for up to 30 days rather than forfeiting them at midnight; every eligible account received one free banked reset on launch day ([CryptoBriefing](https://cryptobriefing.com/openai-codex-free-rate-limit-reset/)). A referral program running through June 24 awards additional banked resets to Plus and Pro users who invite up to three people to send their first Codex message ([CryptoBriefing](https://cryptobriefing.com/openai-codex-free-rate-limit-reset/)). Also on June 11, Anthropic announced Claude Corps, a $150 million program that will place 1,000 early-career fellows at more than 400 U.S. nonprofits for 12-month paid placements at $85,000 annually; CodePath serves as the employer of record and delivers five hours of weekly Claude-focused training throughout each fellowship ([Anthropic](https://www.anthropic.com/news/claude-corps), [Washington Post](https://www.washingtonpost.com/business/2026/06/11/anthropic-ai-claude-corps-daniela-amodei/d11fd0a0-6595-11f1-bdd4-805ebb99a693_story.html)).
