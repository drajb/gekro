Stanford researchers released Memorilla, an open-source memory system that compresses document collections into 16 memory tokens for frozen language models. Testing on Qwen3-8B, Memorilla reached 84.33% accuracy on FactKG while using 108x fewer document tokens than full context approaches. ([MarkTechPost](https://www.marktechpost.com/2026/11/14/stanford-memorilla-memory-system-16-memory-tokens/)) The system addresses a core constraint in production RAG workflows - balancing retrieval quality against token budget and latency without fine-tuning.

Runway released Praxis-1, an open-weight robotics model under the Apache 2.0 license, trained on video data for robot control. The model leads the World Action Model category on Nvidia's RoboLab-120 benchmark, though the company noted it cannot yet plan complex action sequences independently. ([The Decoder](https://the-decoder.com/runways-open-source-praxis-1-turns-video-ai-into-a-robot-controller/)) Separately, Vercel Labs released the Vercel UI SDK, an Apache-2.0 beta library of 50+ UI behaviors that coding agents can compose into accessible components for React, Vue, Svelte, Solid, and Web Components. ([MarkTechPost](https://www.marktechpost.com/2026/11/13/vercel-ui-sdk-agent-ui-behaviors/))
