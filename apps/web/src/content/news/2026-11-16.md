Anthropic published research showing that agent memory quality depends on selective retention rather than storage volume. In testing with Claude Fable 5, the model advanced four times further in a Pokémon Red task by maintaining a small set of strategy notes instead of over 400 archived records, indicating that pruning irrelevant context improves long-horizon performance. ([The Decoder](https://the-decoder.com/anthropic-says-the-key-to-agent-memory-is-knowing-what-to-forget-not-how-much-to-store/)) The finding has direct implications for RAG and multi-turn agent systems where context window management affects both latency and accuracy.

Alibaba released Qwen4-Max, a 2.4-trillion-parameter mixture-of-experts model with 71 billion active parameters, native vision capabilities, and a 1-million-token context window, priced at $1.5 per million input tokens. ([MarkTechPost](https://www.marktechpost.com/2026/11/16/alibaba-qwen4-max-release/)) The model reportedly reduces per-task inference cost by 62 percent on internal Work360 benchmarks. Additionally, Hark released Handoff², an updated computer-use agent that runs 2x faster than its predecessor and completes 82 percent of 478 internal web tasks, achieving performance gains through latency-penalized reinforcement learning that teaches action batching. ([MarkTechPost](https://www.marktechpost.com/2026/11/16/hark-handoff-2-computer-use-agent-2x-faster/))
