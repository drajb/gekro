Nvidia released Flora, an open-source data engine that labels one hour of robot video for $0.72 instead of $88 when using GPT-6 Astra, while achieving slightly higher quality scores. The system is built on three fine-tuned Qwen3.5 models and detects errors in robot actions more reliably than competing approaches, though it occasionally misses edge cases. ([The Decoder](https://the-decoder.com/nvidia-open-sources-flora-to-make-robot-video-labeling-125x-cheaper-than-gpt-6-astra/))

Microsoft Research open-sourced Agensh, a multi-agent harness that orchestrates up to 1,024 agents without a central coordinator. The framework uses self-organizing workers sharing a Git repository, chat interface, and findings board, scaling to ProgramBench tasks within a 6-hour budget. ([MarkTechPost](https://www.marktechpost.com/2026/10/24/microsoft-agensh-multi-agent-harness-1024-agents/)) Separately, Anthropic published research showing single-agent architectures now outperform multi-subagent setups in speed and complexity handling, with a published migration kit available on GitHub to help teams consolidate agent structures. ([The Decoder](https://the-decoder.com/anthropic-says-one-ai-agent-beats-many-subagents-now-that-models-can-handle-complexity-alone/))
