At Build 2026 on June 2, Microsoft announced two in-house AI models developed without OpenAI data or infrastructure ([CNBC](https://www.cnbc.com/2026/06/02/microsoft-unveils-new-ai-models-lessen-reliance-on-openai-lower-costs.html)): MAI-Thinking-1, its first flagship reasoning model ([TechTimes](https://www.techtimes.com/articles/317631/20260602/microsoft-build-2026-mai-thinking-1-first-house-reasoning-model-trained-without-openai-data.htm)), and MAI-Code-1-Flash, a 5-billion-parameter coding model built for GitHub Copilot ([Microsoft AI](https://microsoft.ai/news/introducingmai-code-1-flash/)). MAI-Code-1-Flash applies adaptive reasoning - allocating more compute to complex requests while remaining concise on simple ones - and was trained directly on production Copilot tooling and licensed data to improve performance on real agentic coding workflows ([Microsoft AI](https://microsoft.ai/news/introducingmai-code-1-flash/)). Microsoft reports the model outperforms Claude Haiku 4.5 across four core coding benchmarks, with a 16-point lead on SWE-Bench Pro ([Microsoft AI](https://microsoft.ai/news/introducingmai-code-1-flash/)). Both models are rolling out to all GitHub Copilot plans via the model picker in Visual Studio Code ([Thurrott](https://www.thurrott.com/a-i/336960/build-2026-microsoft-launches-first-flagship-reasoning-ai-model-and-more)).

Anthropic announced an expansion of Project Glasswing - its controlled vulnerability-discovery program using Claude Mythos - to roughly 150 additional organizations across more than 15 countries, now covering power, water, healthcare, communications, and hardware sectors not represented in the initial cohort ([TechCrunch](https://techcrunch.com/2026/06/02/anthropic-scales-claude-mythos-to-critical-infrastructure-in-15-countries/)). Across all scanned targets to date, Mythos has identified more than 10,000 high- or critical-severity vulnerabilities, including a flaw in the wolfSSL cryptography library - used by billions of devices - that would permit certificate forgery for banking and email domains ([Help Net Security](https://www.helpnetsecurity.com/2026/05/26/anthropic-project-glasswing-update/)). In open-model releases, NVIDIA debuted Nemotron 3 Nano Omni on June 1, a 30-billion-parameter mixture-of-experts model that activates roughly 3 billion parameters per inference and combines vision, audio, and language processing in a single architecture for agentic workloads ([NVIDIA Blog](https://blogs.nvidia.com/blog/nemotron-3-nano-omni-multimodal-ai-agents/)); NVIDIA reports 9x higher throughput than comparable open omni models, with weights available on Hugging Face and as an NVIDIA NIM microservice ([The Next Web](https://thenextweb.com/news/nvidia-nemotron-nano-omni-multimodal-agent-edge)).
