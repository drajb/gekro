Gigatoken, an MIT-licensed Rust BPE tokenizer, encodes text at 24.53 GB/s on a 144-core AMD EPYC processor, achieving 989x speedup over HuggingFace Tokenizers and 681x over tiktoken ([MarkTechPost](https://www.marktechpost.com/2026/07/23/meet-gigatoken-a-rust-bpe-tokenizer-that-encodes-text-at-24-53-gb-s-up-to-989x-faster-than-huggingface-tokenizers/)). The gains stem from hand-optimized multithreaded Rust implementation, offering material impact for token-rate-limited inference pipelines and batch processing workloads.

Cursor has made Cursor Router generally available, a request-level classifier that routes queries to the most suitable model based on complexity and task domain, delivering frontier-quality output at 60% savings in A/B tests and 30–50% cost reduction in production deployment ([MarkTechPost](https://www.marktechpost.com/2026/07/22/cursor-releases-cursor-router-a-request-level-classifier/)). In parallel, Anthropic released Claude Security as a beta plugin for Claude Code - a multi-agent vulnerability scanner operating from the terminal that flags issues and auto-generates patches for review ([MarkTechPost](https://www.marktechpost.com/2026/07/22/anthropic-releases-claude-security-plugin-for-claude-code-in-beta-a-multi-agent-vulnerability-scanner-that-runs-in-your-terminal/)).
