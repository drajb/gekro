NVIDIA made Nemotron 3 Ultra available on June 4 under a permissive license, releasing a 550-billion-parameter sparse mixture-of-experts model built on a Mamba-Transformer hybrid architecture ([ChatForest](https://chatforest.com/builders-log/nvidia-nemotron-3-ultra-june-4-launch-open-frontier-agent-model-builder-guide/)). With approximately 55 billion parameters active per token, the model sustains over 300 tokens per second in throughput, supports a 1-million-token context window, and carries an estimated inference cost roughly 30 percent below comparable closed-source frontier models ([AI Tools Recap](https://aitoolsrecap.com/Blog/nvidia-nemotron-3-ultra-550b-computex-2026)). On the Artificial Analysis Intelligence Index, Nemotron 3 Ultra scored 48, placing first among open-weight models developed in the United States and second globally, with Chinese open models still leading the overall leaderboard ([The Decoder](https://the-decoder.com/nvidias-nemotron-3-ultra-becomes-the-smartest-open-us-model-but-china-still-leads/)). Weights and model files are available on Hugging Face, via NVIDIA NIM microservices, and on OpenRouter ([Hugging Face](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16)), with NVIDIA positioning the release as the first open frontier model designed primarily for agentic deployment patterns ([ChatForest](https://chatforest.com/builders-log/nvidia-nemotron-3-ultra-june-4-launch-open-frontier-agent-model-builder-guide/)).

Anthropic on June 1 confidentially submitted a draft Form S-1 registration statement to the Securities and Exchange Commission, initiating the review process for a potential initial public offering ([TechCrunch](https://techcrunch.com/2026/06/01/anthropic-files-to-go-public/), [Anthropic](https://www.anthropic.com/news/confidential-draft-s1-sec)); reporting has placed the target valuation near $965 billion, with a possible listing as early as October 2026 and Wilson Sonsini - the firm that handled Google's 2004 IPO - advising on public-market preparation ([NPR](https://www.npr.org/2026/06/01/nx-s1-5843199/anthropic-ipo-filing-ai-large)). Separately, Anthropic announced that starting June 15, Agent SDK workloads - specifically the claude -p non-interactive flag, Claude Code GitHub Actions, and third-party apps authenticating via the Agent SDK - will draw from a new dedicated monthly credit pool rather than standard subscription usage limits ([TechTimes](https://www.techtimes.com/articles/317625/20260602/anthropic-ends-subscription-subsidy-agents-june-15-credit-pool-replaces-flat-rate-access.htm)). Credit allocations are $20 per month for Pro subscribers, $100 for Max 5x, and $200 for Max 20x, billed at standard API list rates; once the pool is exhausted, automated requests halt entirely unless the user has enabled overflow billing, and unused credits do not roll over ([The New Stack](https://thenewstack.io/anthropic-agent-sdk-credits/), [DevTool Picks](https://devtoolpicks.com/blog/anthropic-splits-claude-subscriptions-agent-sdk-credit-june-2026)). Interactive Claude usage through the chat interface and Claude Code in the terminal is not affected by the change ([The New Stack](https://thenewstack.io/anthropic-agent-sdk-credits/)).
