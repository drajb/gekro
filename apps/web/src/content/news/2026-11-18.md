Hugging Face released Qwen3.8-27B-pi-adapted, an Apache-2.0 LoRA adapter trained with reinforcement learning for the pi coding agent. The adapter lifted SWE-bench Pro hard-51 pass@1 from 39.2 percent to 64.7 percent and Terminal-Bench 2.1 from 39.5 percent to 55.8 percent ([MarkTechPost](https://www.marktechpost.com/2026/11/18/hugging-face-qwen3-8-27b-pi-adapted-lora/)).

Hugging Face now routes language model requests through OpenRouter, which automatically selects the cheapest or fastest provider based on user preference. According to OpenRouter, the new routing reduced capacity errors by 46 percent ([The Decoder](https://the-decoder.com/hugging-face-now-routes-model-requests-through-openrouter-for-the-best-price-or-speed/)). Separately, Anthropic added Code Mode to Claude Code v2.1.323, an experimental feature that lets Claude write JavaScript chaining Bash, Read, and Edit calls in a single step while keeping the conversation active ([MarkTechPost](https://www.marktechpost.com/2026/11/17/anthropic-claude-code-code-mode-javascript-tool-calls/)).
