Alibaba's new Co-Design Bench coding-agent benchmark tested AI agents on real user requests that had previously caused failures in production. ([The Decoder](https://the-decoder.com/ai-coding-agents-still-need-human-cleanup-on-nearly-three-out-of-four-tasks-in-a-real-world-test/)) Even GPT-6 Astra, the top performer, fully solved only 26.4 percent of tasks - a stark contrast to models scoring above 99 percent on older benchmarks. The gap highlights the persistence of real-world complexity in software development that standardized eval suites do not capture, suggesting that human oversight remains critical for production agent deployments.

Google AI released the Elephant-Goldfish Model plugin for coding agents, which enforces a spec-first workflow: agents draft specifications before generating code, then run five zero-context review stages to validate implementation. ([MarkTechPost](https://www.marktechpost.com/2026/11/08/google-elephant-goldfish-model-plugin-spec-review-coding-agents/)) Separately, Nous Research released Arete-27B, an Apache 2.0 fine-tune of Qwen3.8-27B that reduced propaganda output from 22 percent to 0.9 percent on an 803-prompt evaluation while maintaining general capability benchmarks. ([MarkTechPost](https://www.marktechpost.com/2026/11/07/nous-research-arete-27b-qwen3-8-27b-propaganda-fine-tune/))
