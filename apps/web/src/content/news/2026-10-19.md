MiniMax released M3.1 Flash, a 428B-parameter mixture-of-experts model with approximately 23B active parameters and 1M-token context window ([MarkTechPost](https://www.marktechpost.com/2026/10/19/minimax-m3-1-flash-release/)). API pricing is set at $0.15 per 1M input tokens and $0.60 per 1M output tokens, with open weights available October 23 ([MarkTechPost](https://www.marktechpost.com/2026/10/19/minimax-m3-1-flash-release/)). The model targets agentic workloads with extended context support.

NVIDIA open-sourced the Run:ai GPU orchestration platform under Apache 2.0 license, including the KAI Scheduler, CUDA 13.4 GPU fractioning, quota management, and a local Kind development environment ([MarkTechPost](https://www.marktechpost.com/2026/10/18/nvidia-runai-open-source-gpu-orchestration-kubernetes/)). Mistral AI released Timestral, a time series forecasting model family ranging from 5M to 209M parameters, with the 209M variant outperforming Google's TimesFM-3 on zero-shot benchmarks and running on CPU ([MarkTechPost](https://www.marktechpost.com/2026/10/18/mistral-timestral-time-series-foundation-model/)).
