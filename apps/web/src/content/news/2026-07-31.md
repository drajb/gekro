OpenAI reduced pricing for its GPT-5.6 Luna model by 80 percent effective July 30, with a 20 percent cut to the Terra model, citing infrastructure efficiency improvements enabled by its top-tier Sol model ([The Decoder](https://the-decoder.com/openai-goes-full-china-pricing-mode-with-an-80-percent-cut-to-its-most-affordable-gpt-5-6-model/)). The move reflects price competition from lower-cost providers and Microsoft's own MAI models. Separately, Google DeepMind shipped Gemini Robotics 2, a suite of three models for robot control: a vision-language-action model for whole-body humanoid control, Gemini Robotics ER 2 for embodied reasoning and task orchestration, and an on-device VLA model for resource-constrained deployment ([MarkTechPost](https://www.marktechpost.com/2026/07/30/google-deepmind-gemini-robotics-2-whole-body-control-dexterity-multi-robot-collaboration/); [Google DeepMind](https://deepmind.google/blog/gemini-robotics-er-2-powering-robotics-with-video-understanding-task-orchestration-and-multi-robot-collaboration/)).

Nous Research integrated Hermes Agent with Buzz, Block's self-hostable Nostr workspace, via three integration paths including Desktop runtime and a native gateway that preserves agent memory and skills ([MarkTechPost](https://www.marktechpost.com/2026/07/31/nous-research-ships-three-integration-paths-for-hermes-agent-and-buzz-blocks-open-source-nostr-workspace-for-humans-and-agents/)). PolyAI released Dialog-RSN-1, an audio-native dialog model that fuses turn-taking, speech recognition, function calling, and response generation into a single model while keeping TTS separate for voice control ([MarkTechPost](https://www.marktechpost.com/2026/07/30/polyai-releases-dialog-rsn-1-an-audio-native-dialog-model-that-fuses-turn-taking-speech-recognition-function-calling-and-response/)).
